# Revisión humana de Writing A1/A2

Abre `revision_humana.html` en Edge, Chrome o Firefox actualizado. Funciona sin instalación y sin conexión a Internet. Puedes entregar al docente este HTML y la copia de la rúbrica que se encuentra en `analysis_v2/human_review_development60/reviewer_materials/human_review_rubric_v2.md`.

1. Escribe el identificador acordado con el investigador y la fecha. Selecciona la muestra completa de 180 fichas o las 45 de segunda revisión según tu asignación.
2. Lee la consigna, el texto del estudiante y la respuesta íntegra. Decide si el original contiene errores y si puedes evaluar la respuesta. La página no decide estos juicios por ti.
3. Asigna las siete notas, responde los dos juicios, elige el veredicto y justifícalo. Las opciones NA se fijan únicamente cuando tu elección explícita hace que un criterio no aplique. No se prellenan notas de calidad.
4. Pulsa **Guardar evaluación y siguiente**. Las fichas incompletas quedan como borradores y no se exportan como evaluaciones. Si editas una ficha completada, debes volver a completarla.
5. Descarga respaldos periódicamente y antes de cambiar de equipo, navegador o ubicación del HTML. El guardado del navegador depende de sus ajustes y no sustituye el respaldo. **Restaurar respaldo** comprueba que pertenezca a este mismo paquete y pide confirmación antes de sustituir un progreso existente.
6. Pulsa **Exportar evaluaciones**, luego **1. Descargar notas JSONL** y **2. Descargar metadatos JSON**. Entrega ambos archivos al investigador. Cada descarga se solicita por separado. En segunda revisión solo se exportan las fichas de esa asignación. Si editas una ficha, vuelve a preparar la exportación.

La lista permite buscar y filtrar por nivel y estado. Los modelos, el gold, las etiquetas de condición y los puntajes automáticos están ocultos. Si la respuesta menciona espontáneamente un modelo, deja constancia en el fundamento: el contenido se conserva íntegro. Las revisiones son individuales; usa perfiles de navegador o copias con ubicación distinta para evaluadores diferentes y conserva respaldos separados.

Una posible ambigüedad del caso puede señalarse con **Caso posiblemente inválido** y su fundamento. Eso requiere adjudicación del coordinador. Una respuesta con formato JSON defectuoso puede tener contenido lingüístico evaluable.

La página no envía información a Internet. Los archivos descargados contienen tu identificador y tus juicios: entrégalos al coordinador por el medio acordado. La aplicación facilita recoger una evaluación humana; no sustituye a un docente o evaluador.
